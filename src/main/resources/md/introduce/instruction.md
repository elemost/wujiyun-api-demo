# 简介

五极开放平台基于五极云产品，提供开放能力，让用户能够通过该能力，实现企业个性化需求。

![开放平台](https://cos.elemost.com/elemost/openplat-app-secret.jpg)

# 相关功能

此处汇总的开放平台功能需要在五极云产品中配合使用，详细配置参考对应功能模块。

| 功能名称 | 功能说明                        |
|------|-----------------------------|
| 密钥管理 | 用于外部API与五极云直接通信加密           |
| 参数管理 | 用于配置外部API接口传入/传出参数与表单字段对应映射 |

# 触发功能

五极云产品触发功能提供调用开放能力入口，触发功能的使用权限有版本限制，具体详情点击[<u>__五极云官网
__</u>](https://www.elemost.com/price?menu=price)。

# 使用权限

五极云不同版本的用户对开放平台的使用权限有所不同，下表列出使用权限详细信息。如欲增购功能，可联系五极云商务：[13958123626](tel:13958123626)

| 模块     | 入口可见权限 | 功能可用权限 | 用户权限      |
|--------|--------|--------|-----------|
| 开放平台入口 | 所有版本   | -      | 创建者和所有管理员 |
| 密钥管理   | 所有版本   | 仅付费版本  | 创建者       |
| 参数管理   | 所有版本   | 仅付费版本  | 创建者和所有管理员 |

# 应用场景

- 企业第三方系统（如ERP）数据同步至五极云应用
- 五极云应用数据同步至企业第三方系统（依赖触发功能）
